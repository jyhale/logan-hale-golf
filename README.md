# logan-hale-golf

Unofficial season tracker for Logan Hale, University of Denver women's golf (2026–27).

Single self-contained page: `index.html`. No build step, no dependencies beyond Google Fonts.

## Publishing on GitHub Pages

1. Create a public repo named `logan-hale-golf` under the `jyhale` account.
2. Add `index.html` (and this README) to the repo root on the `main` branch.
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder: `/ (root)` → Save.
4. The site appears at https://jyhale.github.io/logan-hale-golf/ within a minute or two.

## Updating

Replace `index.html` and commit. Pages redeploys automatically.

## Sources

Golfstat, Scoreboard powered by Clippd, WAGR, NCAA Division I women's golf pre-championship manual,
West Coast Conference, and Denver athletics. Field ranks and medians are computed from full leaderboards.
